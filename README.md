این اپ یک اپلیکیشن موبایل ساده برای ورزش تیراندازی است که به شما کمک می‌کند عملکرد خودتان را ثبت و دنبال کنید.
ایده اینه که ورزشکار خودش تمام کنترل داده‌ها و نتایجش را داشته باشد، بدون نیاز به مربی یا واسطه.

محاسبه و نمایش امتیاز میانگین و روند پیشرفت
مدیریت نتایج شخصی به صورت ساده و سریع
